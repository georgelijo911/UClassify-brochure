The Problem
Classification is the bottleneck on every new data share.
Manual today
Hours of analyst time per file. Months of effort for an entire classification exercise. Inconsistent across reviewers. Mistakes carry regulatory weight.
Generic AI
Per-call costs that don't scale. No regulatory citation per field — regulators want "this is PCI because rule X fired", not "the model said so".
Our approach
A small, fast, browser-based classifier purpose-built against established regulatory frameworks. Three voters reinforce each other. No data ever leaves the page.
  • SSO-enabled — Secured via enterprise SSO. No separate login — access controlled through existing identity.
  • Privacy by design — Runs entirely in-browser. CSP-enforced. Field names only — never the data.
  • Exportable results — One-click Excel & CSV export with classifier votes, confidence scores, and audit trail.
How It Works
Three voters. One verdict.
Rules
1,504 hand-curated patterns aligned to the Classification Matrix & Information Handling Procedure
Ontology
39,000-field authoritative enterprise dictionary
ML Model
A small neural network (not an LLM) trained on 17,553 hand-labelled fields. 427 KB — runs in-browser. Sees only field names, never values. Abstains below 60% confidence so weak signals never override strong ones.
